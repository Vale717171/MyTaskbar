# MyTaskbar

Taskbar personalizzata per macOS costruita con SwiftUI + AppKit.

## Obiettivo MVP
- Finestra borderless in basso
- App in esecuzione visibili
- Start menu con ricerca app

## Istruzioni
1. Clona questa repo
2. Apri Xcode
3. Crea nuovo progetto **macOS App** (SwiftUI) **dentro** questa cartella
4. Sostituisci i file generati con quelli presenti nella cartella `MyTaskbar/`
